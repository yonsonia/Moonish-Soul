# Moonish Soul

Mobile-first Cantonese oracle-card app prototype. Open index.html or serve it with any static web server. The self-contained HTML includes the application, styles, logo and background grain. No build is required.

Features: daily cards and date-based history stored only in this browser; optional question; six-step reading journey; full 44-card Overhand/Riffle shuffle and fan selection; ordered reveals; custom ten-card cross; inline final summary.

Chinese card readings are original editorial drafts, not official translations. User questions are kept in page memory and are not sent to a server.

Daily messages now start with a direct 44-card choice (no shuffle screen), then preserve the selected card for the local day. moon-options.html compares three proposed moon-phase navigation graphics; it does not change app settings.

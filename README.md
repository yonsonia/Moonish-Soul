# Moonish Soul

Mobile-first Cantonese oracle-card app prototype. Open index.html or serve it with any static web server. The self-contained HTML includes the application, styles, logo and background grain. No build is required.

Features: daily card stored in this browser for the device-local day; optional question; six-step reading journey; full 44-card Overhand/Riffle shuffle and fan selection; ordered reveals; custom ten-card cross; inline final summary.

Chinese card readings are original editorial drafts, not official translations. User questions are kept in page memory and are not sent to a server.
